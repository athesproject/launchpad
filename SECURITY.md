# Security policy

Please report vulnerabilities in the LitVMSwap deployment privately through GitHub: **Security** tab, **Report a
vulnerability**. Do not open a public issue or pull request for a security problem.

Include the contract and network, what an attacker can do, and the steps or a test that shows it. We confirm receipt
within 72 hours and keep you informed until the issue is fixed.

In scope: the LitVM deployments in [deployments/4441.md](deployments/4441.md). Owner roles on LitVM are held by the
2-of-3 Safe `0x868b8B48db5DDE602D24960A606A5A8F93333bf9`. A vulnerability in upstream Doppler code should also go to
Whetstone Research (`security@whetstone.cc`, the contracts' `@custom:security-contact`).
